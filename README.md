🎓 Projet d'Orientation Professionnelle (POP) : Développeur Web

Ce dossier a été réalisé dans le cadre de l'UE Projet d'Orientation Professionnelle durant l'année universitaire 2024/2025. Il retrace une démarche d'exploration approfondie du métier de développeur web, afin d'en comprendre les compétences clés, les réalités du terrain et les perspectives d'évolution.


🎯 Objectifs de la démarche
L'objectif principal était de lever le voile sur les détails techniques et humains de la profession:  

Identifier les compétences techniques (langages, frameworks) et les qualités personnelles requises.  

Comparer les modes d'exercice : indépendant (freelance) vs salarié en agence.  

Évaluer la cohérence entre mes expériences actuelles et les attentes du marché.

🔍 Méthodologie & InvestigationsPour obtenir une vision complète, j'ai croisé plusieurs sources d'information :Recherche documentaire : Analyse de sites spécialisés (Onisep, Jobirl, Linkedin) et de ressources techniques (W3Schools, Zeste de Savoir).  Interviews professionnelles :Jean Jacques (Buzz Micro) : Développeur web indépendant, pour comprendre la gestion de projet de A à Z et la polyvalence nécessaire.  Julian (EnjoyCreative) : Développeur en agence, pour découvrir le travail collaboratif avec des chefs de projet et designers sur des projets complexes.  

📊 Bilan des RésultatsMissions : Conception, écriture de code (HTML, CSS, JS, PHP, Python), résolution de bugs et maintenance applicative.  Compétences clés : Maîtrise des langages web, frameworks (React, Laravel, etc.), gestion de version (Git/GitHub) et bases de données (SQL/NoSQL).  Marché de l'emploi : Secteur très demandé où le diplôme est important, mais où les profils autodidactes motivés ont aussi leur place. 

👤 Bilan Personnel & AtoutsLe dossier analyse également comment mes expériences passées m'ont préparé au monde du travail :Rigueur et gestion du stress : Acquises lors d'un job d'été en boulangerie pendant les périodes d'affluence.  Bases techniques : Apprentissage des algorithmes, de la programmation web et des structures de données durant ma licence.  Savoir-être : Autonomie, curiosité et esprit d'équipe.

🚀 Conclusion & Perspectives
Cette étude a confirmé mon souhait de travailler dans l'informatique. Bien que le développement web soit une voie privilégiée, je garde une ouverture vers le domaine des réseaux. Mon plan d'action immédiat est de renforcer mes compétences sur les frameworks modernes et de multiplier les projets pratiques.
